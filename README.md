# Генераторная станция (ЛР №4, вариант 16)

Учебное приложение по теме «Функции-генераторы и работа со встроенными функциями Python». В программе собраны три задачи варианта 16: площади кругов, бесконечный генератор email-адресов и отбор двузначных чисел через `filter`. Есть окно на PySide6 с вкладками, консольный режим, журнал запусков в SQLite и параллельный генератор адресов для замера скорости. Для запуска нужен Python 3.12 или новее.

Работа выполнена на уровне Well-done: сделаны все требования Rare и Medium, дополнительно реализован параллельный вариант генератора и показано ускорение.

## Задачи варианта

1. Генератор площадей кругов для радиусов от 10 до 100. Первые пять значений выводятся с точностью до сотых по формуле `S = πr²`.
2. Бесконечный генератор email-адресов вида `xxxxxxxx@mail.ru`. Имя состоит из восьми случайных символов строки `ascii_lowercase + ascii_uppercase + "0123456789_"`. Первые семь адресов выводятся на экран.
3. Отбор двузначных чисел из строки. Числа вводятся через пробел, для фильтрации используется `filter`. Двузначным считается число, у которого модуль от 10 до 99, поэтому `-34` тоже подходит.

## Состав проекта

- `genlab/models.py` — проверка чисел, разбор строки, `TaskResult` и `RunRecord`;
- `genlab/exceptions.py` — собственные исключения приложения;
- `genlab/generators.py` — `circle_areas`, `email_addresses`, `only_two_digit`, `parallel_email_addresses`;
- `genlab/storage.py` — журнал запусков в SQLite;
- `genlab/service.py` — расчёты, сохранение истории и экспорт в CSV;
- `genlab/ui.py` — главное окно PySide6 с пятью вкладками;
- `genlab/cli.py` — консольное меню, демонстрация и замер;
- `main.py` — точка входа;
- `tests/` — тесты pytest.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

На Linux или macOS окружение активируется командой `source .venv/bin/activate`. Журнал по умолчанию хранится в файле `genlab.db` рядом с `main.py`. Другой путь можно задать переменной `GENLAB_DB` или параметром `--db`.

Консольный режим:

```bash
python main.py --console
```

Демонстрация без ввода (этот режим запускается в Docker):

```bash
python main.py --demo
```

Замер скорости:

```bash
python main.py --benchmark --count 1000000 --workers 4
```

## Тесты

```bash
pytest tests -v
```

Тесты проверяют формулы, генераторы, валидацию ввода, журнал SQLite, сервис, консольный режим и вкладки окна. Для графических тестов используется `pytest-qt` с платформой `offscreen`.

## Docker

```bash
docker build -t genlab .
docker run --rm genlab
```

Образ собирается на `python:3.12-slim`. В контейнере запускается демонстрационный режим: графическое окно требует дисплея, поэтому для проверки в Docker выбран `--demo`.

## Краткая справка

- Площадь круга: `S = πr²`. Радиусы перебираются без накопления ошибки: `r = start + i * step`.
- Email: 8 символов из набора `A–Z`, `a–z`, `0–9`, `_`; домен `mail.ru`.
- Двузначные числа: `10 <= |n| <= 99`.
- Параллельный генератор делит количество адресов на пачки и передаёт их процессам через `ProcessPoolExecutor`. Каждый процесс получает своё начальное число для `random.Random`.
- Журнал хранит задачу, итог, первые значения, время работы и дату запуска. Экспорт в CSV использует `;` и кодировку `utf-8-sig`, чтобы Excel правильно открыл русские буквы.
- Все ошибки ввода выводятся понятным текстом: пустое поле, текст вместо числа, `NaN`, бесконечность, нулевой шаг, отрицательный радиус.
